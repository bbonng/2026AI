1분 20초 · 소리가 납니다

설치 4단계

  1. Claude 데스크톱 앱 설치claude.ai/download → Windows용. 웹 말고 꼭 앱이어야 해요.
  2. Node.js 설치nodejs.org → LTS 받기 → 계속 Next
  3. 명령 프롬프트(cmd)에 한 줄윈도우 키 → cmd 입력 → 열고 붙여넣기 → Enter
    npx -y kordoc setup
    PowerShell 말고 명령 프롬프트(cmd)로 하세요.
  4. Claude 앱 완전히 껐다 켜기Ctrl+Shift+Esc → Claude → 작업 끝내기 → 다시 실행
설치 안내서 PDF 받기 4쪽

막힐 때 해결법과 처음 써 보는 방법이 들어 있어요.

깔고 나서 이렇게

양식 파일을 마우스 오른쪽 클릭 → "경로로 복사"한 뒤 붙여 넣고 부탁하세요.

"C:\학교\계획서 양식.hwpx" 이 양식대로 ○○ 운영 계획서 만들어 줘. 표와 서식은 그대로 두고, 한글 파일(hwpx)로 저장해 줘.

마음에 들게 나오면 한마디: "이 방식 기억해 둬."
